# ARM Token

## Overview

ARM Token is the native cryptocurrency of the ARMchain ecosystem, designed to power quantum-resistant blockchain operations and provide utility across the entire network.

## Key Features

- Built on post-quantum cryptographic foundations

- Advanced encryption algorithms
